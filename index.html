GreenLeaf Cleaning Co.

A landing page for a home cleaning company that takes a visitor from “who are you?” to “get a quote” in a single scroll.

This is a concept project. GreenLeaf is a fictional business.

Role
Design and front-end development
Built with
React, Tailwind CSS, Vite
Includes
Responsive navigation with a mobile menu, service cards, a testimonial and a quote call to action

Focus Timer

A Pomodoro timer with three modes and a countdown that never drifts.

  1. Focus. Twenty-five minutes, started with one tap.
  2. Pause. The interval is cleared on every pause, so the clock can never tick twice.
  3. Break. Switching mode resets the clock and stops the timer.
Built with
React, Tailwind CSS, Vite

Profile and skills app

A React app that loads a live GitHub profile and keeps a list of skills you can add to.

Built with
React, Tailwind CSS, the GitHub REST API
Includes
Live data with loading and error states, controlled form inputs, and a list that re-renders as you add to it

This site

Designed and built from scratch as a working sample. Every image on this page is drawn in WebGL.

  • Three.js shaders for the develop effect, the loupe and the transitions
  • GSAP ScrollTrigger for the pinned contact sheet and the reveals
  • Lenis for smooth scrolling
  • The View Transitions API for the darkroom switch
  • A Vite build, deployed on Netlify

One person, from sketch to launch.

Working with one person means fewer handoffs. The person who designs your site is the person who builds it, so it behaves the way it was designed, on phones and desktops alike.

What I make

  • Landing pages and marketing sites
  • Portfolio and brand sites
  • Interactive front-ends in React
  • Motion, scroll effects and WebGL

How a project runs

  1. Brief. We agree what the site needs to do and who it’s for.
  2. Design. Layouts and type, shown in the browser early.
  3. Build. Hand-written code, tested on phones and desktops.
  4. Launch. Deployed, fast, and handed over with notes.
