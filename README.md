# Portfolio Site — Project 1

Your personal portfolio: home, about, projects, contact. Built in plain HTML, CSS, and JavaScript
(no framework yet — that's intentional, see Phase 1 of the roadmap).

## Running it locally
Open `index.html` directly in your browser, or (once VS Code + the Live Server extension are
installed) right-click index.html → "Open with Live Server" for auto-refresh while you edit.
